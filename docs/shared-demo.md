# The shared demo

`https://demo.container-registry.com` runs 8gcr / Harbor Next 2.16. The
screenshots and transcripts in this repository were taken there, and you can
log in and look at the projects the examples create.

It is a shared public instance: every account is an admin, so anyone can
change or delete its projects, trusted issuers and robots. Run the examples
against your own 8gcr instance; every setup script takes `HARBOR_URL`.
